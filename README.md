# Evaluacion2 - Software de Geolocalización

## Descripción
Este proyecto consiste en un script interactivo en Python que consume la API de Graphhopper Directions para calcular rutas, distancias y tiempos de viaje con indicaciones paso a paso en español.

## Requisitos
- Python 3.x
- Librería `requests`

## Instrucciones de Ejecución
1. Abrir la terminal y navegar a la carpeta del proyecto.
2. Ejecutar el script:
   python3 graphhopper_parse-json.py
3. Ingrese el origen y destino solicitados. Para salir escriba `s` o `salir`.
